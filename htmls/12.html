Testing: Automated E2E Generation

Step-by-Step Recipe

Scenario

Create E2E tests for "Saved Searches" UI

Goal: Generate resilient Playwright tests from specs and OpenAPI definitions, enabling self-healing selectors and visual regression checks.

Execution Steps

1

Generate Test Scaffold

AI reads spec.md + openapi.yaml to generate Playwright tests.

Maps user stories directly to test cases (e.g., "User saves a filter").

2

Self-Healing & Data Synthesis

Enable AI-driven locators (self-healing) and synthesize mock data.

Generates testdata.json with realistic edge cases (long strings, special chars).

3

Visual Regression Baseline

Run tests to capture screenshots creates visual baseline for UI.

Commit screenshots to repo for CI comparison.

Artifacts Produced

e2e/saved-searches.spec.ts (Test suite)

fixtures/testdata.json (Mock data)

snapshots/*.png (Visual baselines)

Tools Stack

Playwright + AI
LLM Planner
MCP (Schemas)
Visual Regression
