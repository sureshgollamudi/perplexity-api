Planning: From Brief to Spec

Step-by-Step Recipe

Scenario

Input: 1–2 page product brief for "Saved Searches"

Goal: Convert brief into a complete technical specification with user stories, acceptance criteria, and implementation plan using AI assistance.

Execution Steps

1

Draft Initial Spec

In IDE, run /specify (Spec Kit) to process the brief.

AI drafts User Stories + Given-When-Then criteria automatically.

2

Enrich with Context (MCP)

Use MCP to pull top 20 related Zendesk tickets + product analytics.

"Does this match customer pain points from last quarter?"

3

Refine & Commit

AI flags ambiguities & missing edge cases. Refine spec, then commit folder.

Creates the "Source of Truth" for development.

Artifacts Produced

spec.md (User stories, GWT)

plan.md (Implementation steps)

tasks.md (Checklist for dev)

Tools Stack

Copilot / Claude
GitHub Spec Kit
MCP (Zendesk, Analytics)
GitHub Issues

Success Criteria

Spec completeness checklist passes

Traceability established (Spec → Tasks)

Stakeholder review & sign-off
